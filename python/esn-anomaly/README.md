# ESN 異常検知プロトタイプ

Echo State Network (ESN / リザーバコンピューティング) による時系列異常検知の実験実装。
単一チャネルの波形分類から、スパイク検知、2 チャンネル同期信号の監視、
アノテーション付き学習の効果検証まで段階的に拡張した。

## 概要

| 項目               | 内容                                                        |
| :----------------- | :---------------------------------------------------------- |
| サンプリング周波数 | 30 Hz                                                       |
| 信号周波数         | 2 Hz                                                        |
| モデル             | Reservoir (units=200, sr=0.9, lr=0.3) >> Ridge (ridge=1e-6) |
| 学習タスク         | One-step-ahead prediction（1ステップ先予測）                |
| 検知原理           | 予測残差が持続的に閾値を超えると異常と判定                  |

## Phase 7: マルチ波形対応

### アーキテクチャ

```
入力 u(t) ─→ Reservoir ─→ Ridge ─→ 予測 û(t+1)
                                      ↓
                               |u(t+1) − û(t+1)| = 残差 e(t)
                                      ↓
                         smooth(e, window=30) = s(t)
                                      ↓
                     detect_persistent(s, threshold, min_duration=60)
```

### 訓練データ設計

混合訓練: `[sine × 250, sawtooth × 250] × 4 = 2000 step`

| 波形       | スペクトル成分                      |
| :--------- | :---------------------------------- |
| サイン波   | 2 Hz のみ                           |
| ノコギリ波 | 2 Hz + 全高調波（4, 6, 8 … Hz）     |
| 矩形波     | 2 Hz + 奇数高調波（6, 10, 14 … Hz） |

矩形波は訓練データに存在しないスペクトル成分の組み合わせを持つため、
ESN が予測できず高誤差が持続する。

### テストシナリオ結果

| シナリオ             | 構成                                     | 結果              | 確定遅延 |
| :------------------- | :--------------------------------------- | :---------------- | :------- |
| T1 サイン波のみ      | sine × 1000                              | 検知なし ✓        | —        |
| T2 ノコギリ波のみ    | sawtooth × 1000                          | 検知なし ✓        | —        |
| T3 サイン波→矩形波   | sine × 500 → square × 500                | step 565 で確定 ✓ | 2.17 s   |
| T4 ノコギリ波→矩形波 | sawtooth × 500 → square × 500            | step 567 で確定 ✓ | 2.23 s   |
| T5 正常切り替え      | sine × 333 → sawtooth × 333 → sine × 334 | 検知なし ✓        | —        |

### パラメータトレードオフ

`smooth_window` と `min_duration` は追従速度と安定性を同時に決定する。

| パラメータ      | 増やすと                                    | 減らすと                           |
| :-------------- | :------------------------------------------ | :--------------------------------- |
| `smooth_window` | ノイズ耐性↑、正常切替の過渡期長↑、検知遅延↑ | 反応速度↑、過渡期短、ノイズ誤検知↑ |
| `min_duration`  | 安定性↑（誤検知↓）、確定遅延↑               | 検知速度↑、誤検知↑                 |

**設計指針:**

```
1. smooth_window を決定（ノイズ量・反応速度のバランス）
2. 正常切り替えパターンで max_transient を実測
3. min_duration = ceil(max_transient × 1.2) 程度に設定
4. 検知確定遅延 ≈ (smooth_window/2 + min_duration) / fs 秒
```

本実験では正常切替の最大過渡期 ≈ 49 step のため `min_duration = 60`（20% マージン）を採用。
確定遅延 ≈ (30/2 + 60) / 30 ≈ **2.5 s**。

> **注意:** `smooth()` は因果的移動平均（過去 N ステップのみ）を使用する。
> `np.convolve(mode="same")` は中心対称窓のため**未来情報が混入**し、検知が早まる誤動作を起こす。

## Phase 8a: スパイク単発検知

### 問題設定

0.1〜1 Hz の不定期（Poisson 分布）で発生する 1 周期（15 step）スパイクを検知する。

- 正常スパイク: sin / sawtooth（既知波形）
- 異常スパイク: square（未知波形）

### 検知手法

持続判定ではなくスパイク単位の積分 MAE で判定する。

```
1. |u(t)| > spike_threshold でスパイク区間を検出
2. 区間内の残差 e(t) の平均（区間 MAE）をスコア化
3. score > anomaly_threshold（mean + 5σ）で異常判定
```

**閾値設定:**
- `spike_threshold = max(0.3, 2.5 × noise_std)` でノイズに適応
- 異常閾値は 3σ ではなく **5σ** を採用（ノコギリ波の MAE 分散が大きく 3σ では誤検知が発生するため）

### シナリオ結果

| シナリオ                 | 結果              |
| :----------------------- | :---------------- |
| S1 sin スパイクのみ      | 誤検知なし ✓      |
| S2 sawtooth スパイクのみ | 誤検知なし ✓      |
| S3 sin/saw + square 混在 | square 全件検知 ✓ |
| S4 square のみ           | 全件検知 ✓        |

**スパイク MAE の比較:** sin ≈ 0.07、saw ≈ 0.08、**square ≈ 2.43**（約 30 倍の差）

## Phase 8b: SNR × ノイズ種類スイープ

### 設定

| 項目       | 値                                           |
| :--------- | :------------------------------------------- |
| SNR        | 4, 10, 20, 100（noise_std = 1/SNR）          |
| ノイズ種類 | gaussian / uniform / laplacian / pink（1/f） |
| シナリオ   | S1〜S4（スパイク単発、Phase 8a と同様）      |
| 判定       | 4 シナリオ中いくつパスするか（0〜4）         |

### 結果（パスシナリオ数 / 4）

|           | SNR=100 | SNR=20  | SNR=10  |  SNR=4  |
| :-------- | :-----: | :-----: | :-----: | :-----: |
| gaussian  |   4/4   |   4/4   |   3/4   |   1/4   |
| uniform   |   4/4   |   4/4   |   3/4   |   1/4   |
| laplacian |   4/4   |   4/4   |   3/4   |   1/4   |
| **pink**  | **4/4** | **4/4** | **4/4** | **3/4** |

**pink ノイズが最も検知しやすい。**
1/f スペクトルは低周波成分が支配的で、square スパイクの高調波エネルギーが
相対的に際立つことが要因と考えられる。

`S3`（sin/saw + square 混在）が低 SNR で最も失敗しやすい。
混在シナリオでは正常スパイクとの境界判定が難しくなるためである。

## Phase 9a: 2 チャンネル同期信号の異常検知

### 問題設定

```
通常: A(t) = sin(2πft),   B(t) = 0.5 × sin(2πft)  ← 同期・振幅比 0.5 がリファレンス
異常: B の位相シフト (0〜360°) または振幅変化 (0.1〜0.8)
```

異常セグメントの長さは 180〜520 step（6〜17 s）のランダム一様分布。
Poisson 間隔（rate=0.05 Hz）で発生する。

### 検知手法

```
入力 [A(t), B(t)] ─→ ESN（2ch 入出力）─→ 予測 [Â(t+1), B̂(t+1)]
                                              ↓
                              B チャンネル残差 |B(t+1) − B̂(t+1)|
                                              ↓
                              smooth + detect_persistent（min_duration=60）
```

A チャンネルは常に正常なので B の残差のみで判定する。

### シナリオ結果

| シナリオ      | 異常種別       | 結果                 |
| :------------ | :------------- | :------------------- |
| S1 正常のみ   | —              | 誤検知なし ✓         |
| S2 位相シフト | B 位相ランダム | 5/5 セグメント検知 ✓ |
| S3 振幅変化   | B 振幅ランダム | 4/4 セグメント検知 ✓ |
| S4 混合       | 位相＋振幅     | 1/1 セグメント検知 ✓ |

### パラメータスイープ結果（noise_std=0.01）

**位相スイープ（振幅固定 0.5）:**

| 位相差           | 検出率           |
| :--------------- | :--------------- |
| 5°〜330°（全域） | **1.00**（100%） |

30 Hz × 2 Hz では 1 step = 24° に相当するため、
5° の差は 1 ステップ未満でありながらも ESN の記憶が長い区間の残差蓄積で検知可能。

**振幅スイープ（位相固定 0°）:**

| 振幅比               | 検出率   |
| :------------------- | :------- |
| 0.1〜0.45, 0.55〜0.8 | **1.00** |
| **0.50**（正常値）   | **0.00** |

振幅 0.5 の近傍（≈ ±0.05 以内）でのみ検知が難しくなる。

## Phase 9b: アノテーション付き学習の効果検証

### 問題設定

訓練データに異常区間が混在する場合（異常比率 **44.3%**、50% 未満）に
どのような学習戦略が有効かを比較する。

### 4 条件

| 条件                       | 方式                                                      | アノテーション要否 |
| :------------------------- | :-------------------------------------------------------- | :----------------- |
| **A: クリーン**            | 正常データのみで学習（ベースライン）                      | 不要               |
| **B: 汚染**                | 異常込みデータをそのまま学習                              | 不要               |
| **C: マスクリードアウト**  | リザーバは全データで実行。Readout は正常区間のみで学習    | **要**             |
| **D: 3ch Annotation 入力** | 学習時 `[A, B, ann(0/1)]→[A, B]`、テスト時 `ann=0` で推論 | **要**             |

**条件 C の実装:**
```python
# 1. _esn.fit(X, y) でリザーバ初期化
# 2. _reservoir.reset() → _reservoir.run(X) で全区間の状態列を取得
# 3. _readout.fit(states[normal_mask], y[normal_mask]) で正常区間のみ学習
model.fit_masked(X_train, y_train, normal_mask)
```

### 結果比較

| 条件            | S1 正常 | S2 位相 | S3 振幅 | S4 混合 | 閾値   |
| :-------------- | :-----: | :-----: | :-----: | :-----: | :----- |
| **A: クリーン** |    ✓    |  5/5 ✓  |  2/2 ✓  |  4/4 ✓  | 0.0127 |
| **B: 汚染**     |    ✓    |  3/5 ✗  |  0/2 ✗  |  2/4 ✗  | 0.0344 |
| **C: マスクRO** |    ✓    |  5/5 ✓  |  2/2 ✓  |  4/4 ✓  | 0.1129 |
| **D: 3ch ann**  |    ✓    |  5/5 ✓  |  2/2 ✓  |  4/4 ✓  | 0.0264 |

### 考察

**条件 B（汚染）の劣化:**
モデルが「振幅 0.1〜0.35 や 0.65〜0.8 の B も正常である」と学習し、
S3（振幅異常）の検出率が **0%** に低下する。
閾値が 0.034 に上昇するが、異常時の残差も同程度に下がるため検知できない。

**条件 C（マスクリードアウト）の復元:**
リザーバは異常データを通るため内部状態が汚染されるが、
Readout の学習が正常区間のみなので **B の「あるべき値」を正確に予測**できる。
閾値が 0.113 と高くなるのは、異常区間後の過渡状態が正常区間の先頭で
Readout に引き継がれ、正常区間でも予測誤差が一時的に上昇するため。
それでも異常時の残差はさらに大きいため、性能はクリーン学習と同等に回復する。

**条件 D（3ch アノテーション入力）の効果:**
学習時 `ann=1` の期間は「異常パターンを ann=1 チャンネルと関連付け」て学習し、
テスト時に `ann=0` を与えることで「正常パターンのみを予測」するよう誘導する。
閾値は 0.026（クリーンの 2 倍程度）で検知性能も完全回復。

**実用的な推奨:**
| 状況                               | 推奨方式                  |
| :--------------------------------- | :------------------------ |
| 正常データのみ収集可能             | A（クリーン）             |
| 汚染データしかない・アノテなし     | B（汚染）: 性能劣化に注意 |
| アノテーションあり・実装シンプルに | C（マスクRO）             |
| アノテーションあり・より明示的に   | D（3ch ann）              |

## アーキテクチャ詳細

```
入力 u(t)  ──────────────────────────────────→ [学習: one-step-ahead]
  shape (n, d)                                    y(t) = u(t+1)
      │
      ↓
  Reservoir（固定ランダム重み、リーク統合）
      │  x(t+1) = (1-lr)×x(t) + lr×tanh(W_res×x(t) + W_in×u(t))
      ↓
  状態 x(t)  shape (n, units)
      │
      ↓
  Ridge Readout（リッジ回帰で学習: W_out = (X^T X + λI)^{-1} X^T Y）
      │
      ↓
  予測値 û(t)  shape (n, d)
```

### ESN ハイパーパラメータ

| パラメータ | 値   | 説明                                     |
| :--------- | :--- | :--------------------------------------- |
| `units`    | 200  | リザーバニューロン数                     |
| `sr`       | 0.9  | スペクトル半径（記憶-安定性の均衡）      |
| `lr`       | 0.3  | リーク率（時定数の逆数に相当）           |
| `ridge`    | 1e-6 | リッジ正則化係数                         |
| `warmup`   | 100  | 初期過渡状態を学習から除外するステップ数 |

## 実装ノート

### `smooth()` は因果的移動平均を使う

```python
# NG: np.convolve(mode="same") は中心対称 → 未来の誤差が現在に混入
# OK: cumsum ベースの過去 N ステップのみ
cs = np.cumsum(np.insert(errors, 0, 0.0))
end_idx = np.arange(1, n + 1)
start_idx = np.maximum(0, np.arange(n) - window + 1)
return (cs[end_idx] - cs[start_idx]) / (end_idx - start_idx)
```

### ESN の 2D 入出力

`reservoirpy` の `Reservoir >> Ridge` パイプラインは多次元入出力を透過的に扱う。

```python
u = np.stack([A, B], axis=1)   # shape (n, 2)
model.fit(u[:-1], u[1:])       # 2ch 同時予測
pred = model.predict(X_test)   # shape (n, 2) が返る
e_b = np.abs(u[1:] - pred)[:, 1]  # B チャンネル残差
# ⚠ compute_residual() は .ravel() で 1D 化するため 2D 残差には直接使わない
```

### `fit_masked` — アノテーション付き Readout 学習

```python
model.fit_masked(X_train, y_train, normal_mask)
# normal_mask: shape (n,), True=正常区間
# リザーバは全データで実行（状態連続性を保つ）
# Readout は normal_mask=True の区間のみで Ridge 回帰
```

## 今後の課題

| 課題                                   | 対処案                                                      |
| :------------------------------------- | :---------------------------------------------------------- |
| Phase 8b の低 SNR 検知（SNR=4）        | SNR 適応型スパイク閾値、より大きな訓練セット                |
| Phase 9a の検知遅延（min_duration=60） | 残差の微分や勾配を補助特徴として持続判定を高速化            |
| 混合訓練での RMSE 増加                 | units を 400〜500 に増やす、per-wave アンサンブル           |
| 位相 0° 近傍の検知死角                 | B/A の相関係数やクロススペクトル密度を特徴量に追加          |
| アノテーション学習の条件 C の閾値上昇  | 異常セグメント後のウォームアップ区間を除外して閾値安定化    |
| Jetson への移植                        | Phase 4 完了後にリポジトリごと持ち込み（目安 < 33 ms/step） |
